Autoclipper

Autoclipper is a private, non-commercial tool. It prepares short vertical (9:16) clips from Counter-Strike livestreams and, after a member of our small team approves each clip, uploads it to the owner's own TikTok and YouTube accounts.

  • It is not a public service: there is no sign-up, and it is used only by its owner and a few team members.
  • It connects only to accounts we own, through the official TikTok Content Posting API (upload to drafts) and the YouTube Data API v3.
  • It only uploads videos. It does not read, collect or share data about other users.
